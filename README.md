# Mini Survival: Limit Break

단일 HTML 파일로 실행되는 2D 브라우저 서바이벌 게임입니다.

## 플레이

GitHub Pages: https://sunghwanyun80.github.io/seohoo-mini-survival/

- PC: 방향키/WASD 이동, Space 대시, P/Esc 일시정지, Enter 다음 웨이브
- 모바일: 터치 조이스틱 이동, DASH 버튼
- 별도 설치 없이 최신 웹 브라우저에서 실행

## 주요 내용

- 웨이브 전투, 상점, 무기 성장과 합성
- T1~T5 플레이어 함선 디자인
- 다양한 적 함대와 보스
- 후반 심연 난이도
- 모바일 성능 자동 조절과 런타임 오류 대응

## 개발 방식

실제 플레이 피드백을 바탕으로 시각 디자인, 후반 난이도, 모바일 성능과 정지 오류를 반복적으로 개선했습니다. 상세한 버전별 HTML과 개발 과정은 비공개 포트폴리오 저장소에 보존되어 있습니다.

## 공개 범위

이 공개 저장소에는 실행 가능한 최종 배포본과 기술적인 버전 정보만 포함합니다.
